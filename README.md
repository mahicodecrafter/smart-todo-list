# 📝 Tasks — Minimal & Responsive To-Do List

A minimal, fast, and responsive daily task manager built with vanilla HTML5, CSS3, and JavaScript. Tasks are persisted using browser `localStorage` and smoothly animated.

## ✨ Features
- ⚡ **Minimalist, High-Focus UI**: Clean typography, distraction-free interface, and responsive layout for mobile, tablet, and desktop.
- 🌓 **Dark / Light Mode**: Built-in theme switch with automatic preference detection and persistence.
- 🎬 **Fluid Micro-Animations**: Smooth slide-in, checkmark transitions, and animated task deletion.
- 🏷️ **Task Priorities**: Assign Low, Medium, or High priority with subtle color-coded indicators.
- 🔍 **Instant Search & Filters**: Live client-side task search (shortcut `/`) and filter tabs (`All`, `Active`, `Completed`).
- 📊 **Progress Indicator**: Hairline completion progress bar and remaining items counter.
- ↩️ **Undo Toast**: Quick one-click undo notification when tasks are deleted.
- ✏️ **Inline Editing**: Double-click any task title to edit it inline with `Enter` / `Escape` support.
- 💾 **Local Storage Persistence**: Backward-compatible local storage sync keeping your data safe across page refreshes.

## 🛠️ Tech Stack
- **HTML5**: Semantic, accessible markup.
- **Vanilla CSS**: Custom CSS tokens, system fonts, and micro-animations with zero heavy dependencies.
- **JavaScript (ES6+)**: Modular, state-driven DOM rendering and event management.

## ⌨️ Keyboard Shortcuts
- `Enter` — Add new task or save inline edit
- `Esc` — Cancel inline edit
- `/` — Focus search input
