# 📝 To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.
Tasks are stored in the browser using Local Storage, so your tasks remain available even after refreshing or reopening the browser.

## ✨ Features
- ➕ Add new tasks
- ✅ Mark tasks as completed
- 🗑️ Delete tasks
- 💾 Save tasks using Local Storage
- 🔄 Tasks remain after page refresh
- 📱 Responsive design
- 🎨 Simple and user-friendly interface

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- Browser Local Storage

💡 How It Works
The application uses JavaScript to manage tasks.
When a task is added, updated, or deleted, the task list is stored in the browser's Local Storage.
This allows the tasks to remain available even after refreshing the page.
